# Nawajiz — نواجز

Arabic RTL beauty-store demo. Built with HTML, CSS and vanilla JavaScript for GitHub Pages.

## Features
- Responsive desktop and mobile storefront using supplied Nawajiz artwork
- Eight fictional products with generated product photography
- Search, categories, price sorting and favorites
- Persistent browser-local shopping bag with quantities
- Product details and explicitly simulated checkout
- Keyboard-accessible dialogs and reduced-motion support

No backend, payment, real ordering or customer-data collection is configured. Products, prices and promotions are illustrative. Existing campaign claims are supplied artwork, not active commercial promises.

## Run
Serve this folder with any static HTTP server. GitHub Pages uses `main` at the repository root.

## Edit
Products and labels: `app.js`. Layout: `index.html`. Design and responsive rules: `style.css`. Images: `assets/`.

## Asset provenance
Logo, category icons and four campaign banners supplied by the project owner. WebP derivatives are optimized for web delivery. `assets/products.webp` is an AI-generated fictional product contact sheet, generated with the built-in image generation tool; see `ASSET-PROMPT.md`. No third-party product names or reviews are claimed.
