# Nawajiz Beauty

## Product
Arabic RTL demo beauty store using the supplied Nawajiz identity and campaign assets. User explicitly authorized fictional products and prices, a demo cart, and GitHub publishing. No payment collection, no real orders, no invented reviews or certifications. Saudi riyal used as an illustrative currency, inferred from campaign imagery. Static HTML/CSS/JavaScript chosen for GitHub Pages.

## Design direction
Soft editorial storefront: ivory canvas, navy typography, restrained brand orange, spacious product photography, gentle hover transitions. Supplied banner typography and logos are preserved. A wide care campaign leads, followed by category navigation and a four-column product edit. Cart is a focused drawer, detail is a dialog, catalog filtering stays on the page. Mobile uses a two-column catalog and horizontally scrollable categories.

## Implementation scope
Search, category and sale filtering, sort, persistent favorites and cart, product details, quantity updates, clear cart, demo order confirmation. Explicit empty states, keyboard access, reduced motion, and local-only persistence.
